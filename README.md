# Барбер Сүгүр — сайт + онлайн-запись + админ-панель

## Запуск локально
1. Установите Node.js 18 или новее.
2. В папке проекта выполните `npm install`.
3. Задайте переменные окружения `SETUP_CODE` и `ADMIN_PASSWORD` (либо используйте первичную настройку через `SETUP_CODE`).
4. Запустите `npm start` и откройте `http://localhost:3000`.
5. Панель администратора: `http://localhost:3000/admin`.

## Панель администратора
- Логин по умолчанию: `zhlmnvsr` (меняется через `ADMIN_USER`). **Обязательно задайте свой пароль через `ADMIN_PASSWORD`** — если он не задан, сервер использует временный пароль по умолчанию и выводит предупреждение в консоль.
- Просмотр всех записей и фильтрация по статусу и дате.
- Статистика: всего записей, ожидают подтверждения, записи на сегодня, клиенты, которые пришли.
- Подтверждение и отклонение записи.
- Отметка «Клиент пришёл».
- Удаление отдельной записи.
- Список автоматически обновляется каждые 10 секунд.

## Переменные окружения
- `SETUP_CODE` — секретный код для первоначальной установки пароля администратора.
- `ADMIN_PASSWORD` — необязательный пароль администратора, задаваемый через окружение. Не храните его в публичном репозитории.
- `ADMIN_USER` — логин администратора (по умолчанию `zhlmnvsr`).
- `PORT` — порт сервера (по умолчанию 3000).
- `DATA_DIR` — каталог для постоянного хранения `data.json`. На хостинге укажите постоянный диск/volume, иначе данные могут пропасть после перезапуска или redeploy.
- `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID` — необязательные уведомления в Telegram.
- `WA_TOKEN`, `WA_PHONE_ID` — необязательные WhatsApp Cloud API хабарламалары.

## Маңызды
Сайттағы онлайн-жазба сервер арқылы сақталады. `index.html` файлын тікелей ашпаңыз: сайтты Node.js сервері арқылы іске қосыңыз. Хостингке жариялағанда HTTPS қолданыңыз және `DATA_DIR` тұрақты дискке бағытталғанын тексеріңіз.


## Что нового (версия 3)
- Языки: қазақша / русский / English (кнопка KZ/RU/EN в шапке). Тексты: `public/i18n.js` (словарь) и `public/ext.js`.
- Новые разделы: Работы (до/после), Мастер, Отзывы, Вопросы (FAQ), карта в «Приходи».
- Фото для «Работ»: положите в `public/gallery/` файлы `1-before.jpg`, `1-after.jpg` … (см. README там). Фото мастера: `public/img/barber.jpg`.
- Настройки новых разделов — в начале `public/ext.js` (объект `EXT`): подарок каждые N визитов, показ заглушек, 2GIS-ссылка и т.д.
- Отзывы приходят на проверку: админка (/admin) → блок «Отзывы» → «Опубликовать».
- Комбо-услуги в прайсе: «Стрижка + борода + чистка лица» и «Отец + сын» (цены = сумма; меняются в `SV` в index.html и server.js).


## Карта и мобильная версия (исправления)
- Карта: адрес теперь ищется вместе со страной («Уральск, Казахстан»), на телефонах карта не «ловит» прокрутку страницы (нужно нажать на карту, чтобы двигать её), добавлены кнопки маршрута: Google Maps, Apple Maps (только iPhone/iPad) и 2GIS.
- Для точной точки задайте `MAP_LL:'широта,долгота'` в начале `public/ext.js` (координаты можно скопировать из Google Maps → правый клик по точке).
- Исправлено: кнопки в шапке («Записаться», «Админ») вылезали за экран из-за конфликта CSS-классов; музыка сжата (5.8 МБ → 2 МБ) и больше не загружается заранее; кнопка музыки не перекрывает контент.
